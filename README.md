# PointForge

PointForge is an experimental open-source browser-based 3D project focused on procedural characters, animation, locomotion, flight, effects, and interactive systems.

Current characters include:

- VANTA-9 humanoid cyborg
- Cyborg Dragon

## Contributing

Contributions are welcome.

You can help improve:

- Animation
- Procedural rigging
- Three.js rendering
- Performance
- Physics
- IK
- Flight systems
- Character controls
- Effects
- UI
- New features

Fork the repository, make your changes, and submit a Pull Request.
