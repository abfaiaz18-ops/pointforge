# PointForge

PointForge is an experimental open-source browser-based 3D project focused on procedural characters, animation, locomotion, flight, physics, visual effects, and interactive character systems.

It is primarily a personal experimentation project that I continue to evolve through repeated iterations.

I started building PointForge without a traditional programming or 3D-development background and have used ChatGPT extensively throughout the development process.

The characters are not imported 3D models. Their geometry, rigs, movement systems, animation logic, effects, controls, and behavior are created procedurally in code using Three.js and browser technologies.

## No Imported Character Assets

The current PointForge characters are generated and controlled through code.

The project does not rely on imported character models or premade character animations for VANTA-9 or the Cyborg Dragon.

The characters are constructed from procedural geometry and runtime systems implemented in the browser.

This includes systems such as:

- Character geometry
- Mechanical structures
- Rigging
- Articulation
- Locomotion
- Flight
- Wing movement
- Tail movement
- Weapons
- Effects
- Camera behavior
- Character controls
- Animation logic

Three.js is used as the underlying 3D rendering library.

## Development Philosophy

PointForge is not intended to be treated as a finished product.

It is an evolving experimental codebase.

Systems may be redesigned, replaced, expanded, optimized, or removed as development continues.

The main idea is simple:

**keep building, testing, breaking, improving, and experimenting.**
