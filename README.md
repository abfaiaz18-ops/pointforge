# PointForge

PointForge is an experimental open-source browser-based 3D project focused on procedural characters, animation, locomotion, flight, physics, visual effects, and interactive character systems.

The goal is to keep evolving the project through experimentation and community contributions.

## Live Demos

### VANTA-9 Humanoid Cyborg

[Launch VANTA-9](https://abfaiaz18-ops.github.io/pointforge/robot.html)

Interactive humanoid cyborg featuring systems such as:

- Ground locomotion
- Sprinting
- Jumping
- Flight
- Acrobatics
- Dance animations
- Procedural articulation
- Weapons
- Camera controls
- Replay controls
- Visual effects

### Cyborg Dragon

[Launch Cyborg Dragon](https://abfaiaz18-ops.github.io/pointforge/dragon.html)

Interactive mechanical dragon featuring systems such as:

- Quadrupedal locomotion
- Walking, trotting, running, and sprinting
- Jumping and landing
- Articulated wings
- Gliding and flight
- Tail movement
- Dorsal propulsion
- Plasma breath
- Procedural animation
- Camera controls

## Project Goals

PointForge is an evolving playground for experimenting with:

- Procedural animation
- Character rigging
- Inverse kinematics
- Character locomotion
- Flight mechanics
- Creature movement
- Physics
- Three.js and WebGL rendering
- Procedural geometry
- PBR materials
- Particle effects
- Character abilities
- Camera systems
- Performance optimization
- Interactive environments
- Experimental gameplay systems

### How to Contribute

1. Fork this repository.
2. Create your own branch.
3. Make your changes.
4. Test your changes.
5. Submit a Pull Request.
6. Explain what you changed and why.

Pull Requests, experiments, optimizations, fixes, and new ideas are welcome.

## Development Philosophy

PointForge is experimental.

The project is intended to be continuously improved rather than treated as a finished product.

If you think a system can be made faster, smoother, smarter, more realistic, more beautiful, or simply more fun:

**fork it, build it, and send a Pull Request.**

## Open Source

PointForge is open source so developers, artists, technical animators, Three.js developers, game developers, and curious experimenters can study it, modify it, and build on it.

Community contributions are encouraged.
